EducAR is a learning system for teaching basic science courses at the Universidad Autónoma de Bucaramanga (UNAB). It uses Augmented Reality as an integrating technology between theory and practice, making it easier to grasp new concepts and encouraging students' interest in the related courses.

It was built with Unity 3D (version 5.3.1), a 2D and 3D game development platform that targets both mobile and desktop devices, together with the Vuforia SDK for building Augmented Reality applications, which uses the device's screen to project the augmented content.
